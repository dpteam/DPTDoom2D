Моды для DPT.DOOM 2D
====================

Положи сюда файл .wad, .pk3 или .zip — он появится в лаунчере в разделе
"Моды", и его можно будет включить галочкой. Игра получит его через -file.

PK3 — это обычный ZIP. Внутри может быть:

  * один или несколько .wad  — подключаются по очереди, поздние перекрывают
    ранние, как цепочка -file;
  * отдельные лампы (.lmp, .vgaimg, .dmi, .dmm) — заменяют ресурс с тем же
    именем, так что один спрайт или одна карта патчится без WAD.

Собрать PK3 из папки, посмотреть содержимое, распаковать обратно:

  dptdoom2d.exe --modbuild mymod.pk3 modsrc\
  dptdoom2d.exe --modlist mymod.pk3
  dptdoom2d.exe --modunpack mymod.pk3 modsrc\

Формат карт — только родной Doom2D (Doom2D\x1A, версия 2), не Doom/Doom II.
