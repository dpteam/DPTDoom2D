# Управление

Раскладок две, и это шаблоны, как в эмуляторе: шаблон задаёт все клавиши обоих
игроков сразу. Отдельную клавишу можно перепривязать в оверлее, не меняя шаблон —
тогда набор становится «своим».

| | Шаблон 1 — основной | Шаблон 2 — как в 1996 |
|---|---|---|
| Когда | по умолчанию | `-layout 2` или `layout=2` |
| Идея | стрелки + Z/X, как геймпад Денди | родная таблица `main.c` |
| Игрок 1 | `←` `→` `↑` `↓`, `Z`, `X` | `Num 4` `Num 6` `Num 8` `Num 5`, `Page Down`, `Delete` |
| Игрок 2 | `J` `L` `I` `K`, `F`, `G` | `S` `F` `E` `D`, `A`, `Q` |

## Шаблон 1 — стрелки + Z/X (по умолчанию)

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Влево / вправо | `←` / `→` | `J` / `L` |
| Смотреть вверх / вниз | `↑` / `↓` | `I` / `K` |
| Огонь | `Z` | `F` |
| Прыжок | `X` | `G` |
| Использовать (открыть дверь, нажать) | `C` | `H` |
| Оружие назад / вперёд | `Q` / `E` | `R` / `T` |

Логика — как у геймпада: правая рука на стрелках, левая на огне и прыжке, `Z`
слева от `X` так же, как `B` слева от `A` на Денди. Второй игрок получает
кластер `IJKL` с `F`/`G`/`H` слева — так двое не толкаются за одни клавиши.

## Шаблон 2 — numpad, как в `main.c`

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Влево / вправо | `Num 4` / `Num 6` | `S` / `F` |
| Смотреть вверх / вниз | `Num 8` / `Num 5` | `E` / `D` |
| Огонь | `Page Down` | `A` |
| Прыжок | `Delete` | `Q` |
| Использовать (открыть дверь, нажать) | `Num 8` | `E` |
| Оружие назад / вперёд | `Home` / `End` | `1` / `2` |

Это таблица из `main.c` без единого изменения — для тех, кто учил Doom2D в
1996-м и не хочет переучиваться. `Num 8` и на «вверх», и на «использовать» —
так в оригинале.

Если `NumLock` выключен, цифровая клавиатура работает как стрелки — игра читает
те же клавиши, так что это нормально.

## Как сменить раскладку

1. **В игре:** `F2` → вкладка **Keys** → строка **Layout** → `←`/`→`.
   Применяется сразу и запоминается.
2. **В лаунчере:** поле «Раскладка управления». Пустое значение — «как в игре»,
   то есть лаунчер не трогает клавиши и ваши привязки переживают запуск.
3. **Командной строкой:** `-layout 1` или `-layout 2`; в `default.cfg` —
   строка `layout=2`.

Выбор шаблона задаёт остальные клавиши сразу. Привязки, сохранённые оверлеем,
привязаны к шаблону, на котором их сделали (`layout_saved` в
`Storage/default.cfg`): тот же шаблон в лаунчере их сохраняет, другой —
сбрасывает. Смешать «шаблон 2 плюс вчерашние правки от шаблона 1» было бы
сюрпризом, а не удобством.

Строки клавиш в `default.cfg` — наоборот, обычная настройка: они уточняют
шаблон, как `-sndvol` уточняет громкость.

## Как перепривязать одну клавишу

`F2` → **Keys** → строкой **Player** выберите `P1` или `P2` → встаньте на
действие → `Enter` (или `←`/`→`) → нажмите новую клавишу. `Esc` отменяет
захват, `Tab` переключает вкладку.

Привязки сохраняются в `Storage/default.cfg` и подхватываются при следующем
запуске. Удалите этот файл — вернётесь к шаблону. Строка **Layout** при этом
честно показывает `custom`, как только набор перестал совпадать с шаблоном.

Те же привязки можно задать в `default.cfg` рядом с exe или в `Data`:

```
pl1_jump=n
pl1_fire=z
pl2_left=j
layout=1
```

Имена — те, что понимал оригинал: один символ, `up`, `left shift`, `kp 4`,
`page down`, ... Полный список — в `Config.KeyByName`.

## Глобальные

| Клавиша | Что |
|---|---|
| `Esc` | меню (из игры), закрыть меню |
| **`F2`** | **оверлей: монитор и настройки** |
| `F1` | скриншот в `Data/Screenshots/shotNNNN.bmp` |
| `F3` | громкость |
| `F4` | яркость |
| `F6` | сохранить игру |
| `F7` | загрузить игру |
| `F10` | выход с подтверждением |

Сохранение и загрузка переехали с `F2`/`F3` на `F6`/`F7`, потому что `F2` теперь
открывает оверлей.

## Оверлей (F2)

Шесть вкладок, переключение — `Tab`, закрытие — `F2`.

| Вкладка | Что |
|---|---|
| **Monitor** | fps, карта, состояние, координаты, жизни/броня, оружие, монстры, предметы, музыка, масштаб |
| **Video** | масштаб (1x…6x, fit), растяжение (pixel / nearest / smooth), яркость, показ fps, полный экран |
| **Audio** | громкость звука, громкость музыки, смена трека, mute |
| **Game** | читы в deathmatch, полёт, бессмертие |
| **Keys** | шаблон раскладки, игрок P1/P2, девять привязок — перепривязка на месте |
| **Log** | последние события: запуск, скриншоты, сеть, десинк |

Вкладка **Monitor** пассивная: игра продолжается, пока она открыта, так что
цифры можно смотреть на ходу. Остальные вкладки забирают клавиатуру — иначе
стрелка «вправо», меняющая масштаб, ещё и двигала бы игрока.

Настройки пишутся прямо в игру: нет шага «применить» и нет шанса, что оверлей и
движок считают по-разному.

### Растяжение

| Режим | Что делает |
|---|---|
| **pixel perfect** | целочисленный масштаб, поля по краям — пиксели квадратные, картинка ровно как в оригинале |
| **nearest** | заполняет окно, nearest-neighbour — резко, но пиксели неровные |
| **smooth** | заполняет окно, билинейно — мягко, для больших и HiDPI-экранов |

По умолчанию — **nearest**: полноэкранный режим на 16:9 без чёрных полос.
`pixel perfect` — это «как в 1996», с полями.

### Размер панели

Панель считается от размера клиентской области на каждом кадре, а не берётся
фиксированной. При масштабе 1x окно всего 320×200, поэтому панель занимает его
целиком, шрифт меньше, а подсказка внизу скрыта — иначе текст Log и значения
настроек не влезали. На 6x та же панель центрируется как 580×400.

Текст в табах измеряется через GDI (`GetTextExtentPoint32`) и центрируется в
своём прямоугольнике, значения настроек выравниваются по правому краю — так
ничего не обрезается при любом шрифте и DPI.

## Читы

Вводятся прямо в игре, регистр не важен. Работают в одиночной игре и в коопе; в
deathmatch по умолчанию выключены (`-cheat` включает, а в сети — через оверлей).

| Код | По-русски | Что делает |
|---|---|---|
| `IDDQD` | — | снять 400 единиц урона — «бог» на один раз |
| `UJHTW` | **ГОРЕЦ** | переключить бессмертие |
| `TANK` | — | 200 жизней и 200 брони |
| `RAMBO` | — | всё оружие, все ключи, 30000 патронов |
| `BULLFROG` | — | прыжок ×2 |
| `FORMULA1` | — | скорость ×3 |
| `,TKSQJHTK` | **БЕЛЫЙ ОРЁЛ** | полёт |
| `CBVCBV` | **СИМСИМ** | открыть все двери на уровне |
| `GOODBYE` | — | выйти с уровня |
| `GJITKYF` + две цифры | **ПОШЁЛ НА** | прыгнуть на уровень (`GJITKYF05`) |

### Обе раскладки

Кириллические коды — это те же клавиши, набранные на русской раскладке:
`UJHTW` = ГОРЕЦ, `,TKSQJHTK` = БЕЛЫЙ ОРЁЛ, `CBVCBV` = СИМСИМ,
`GJITKYF` = ПОШЁЛ НА.

Работают **с любой раскладки**, как в DOS-оригинале: игра читает не символ, а
физическую клавишу, поэтому ГОРЕЦ и `UJHTW` дают одну и ту же
последовательность. Латинские коды (`IDDQD`, `TANK`, `RAMBO`, `BULLFROG`,
`FORMULA1`, `GOODBYE`) тоже набираются по позициям, так что на русской
раскладке они вводятся как «ШВВЙВ» и т.п. — нажимать надо те же клавиши.

## Аргументы командной строки

```
-file <file.wad>     подключить дополнительный WAD или LMP
-config <file>       свой конфиг вместо default.cfg
-warp <N>            начать с уровня N
-map-pack <name>     пак кастомных карт из Data/Maps
-scale <1..6|0>      масштаб окна (0 = по размеру окна)
-stretch <mode>      pixel | near | smooth (растяжение кадра)
-fullscr / -window   полный экран или окно
-gamma <0..4>        яркость
-sndvol <0..128>     громкость звука
-musvol <0..128>     громкость музыки
-cheat               разрешить читы в deathmatch
-mon                 включить монстров в deathmatch
-layout <1|2>        раскладка: 1 — стрелки + Z/X, 2 — numpad (1996)
-pl1_<action> <key>  одна привязка: pl1_jump, pl1_fire, pl2_left, ...
```

### Сеть

```
-net host            хостить сессию
-net join            подключиться к сессии
-address <ip[:port]> адрес хоста для join
-port <N>            порт (по умолчанию 5041)
-password <text>     пароль сессии
-map <N>             стартовая карта (у хоста)
-deathmatch          режим deathmatch вместо кооператива
-master <ip[:port]>  адрес мастер-сервера
-relay               хостить через релей (не нужен проброс портов)
-relay-session <id>  подключаться через релей по id сессии
```

Подробности — в [NETWORK.md](NETWORK.md).

```
--music, --sounds, --cheats, --controls, --maps, --proto-list, --proto <id>,
--modbuild, --modlist, --modunpack, --wadbuild, --wadlist,
--dump, --list
```

Порты и брандмауэр: `tools/firewall.ps1` и `tools/run-master.ps1`
