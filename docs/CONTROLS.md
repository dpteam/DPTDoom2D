# Управление

Привязки — те же, что в оригинале (`main.c`, `default.cfg`). Менять пока можно
только в `default.cfg` рядом с exe; экрана настройки клавиш нет.

## В игре

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Влево / вправо | `Num 4` / `Num 6` | `S` / `F` |
| Смотреть вверх / вниз | `Num 8` / `Num 5` | `E` / `D` |
| Огонь | `Page Down` | `A` |
| Прыжок | `Delete` | `Q` |
| Использовать (открыть дверь, нажать) | `Num 8` | `E` |
| Оружие назад / вперёд | `Home` / `End` | `1` / `2` |

Если `NumLock` выключен, цифровая клавиатура работает как стрелки — это
нормально, игра читает те же клавиши.

## Глобальные

| Клавиша | Что |
|---|---|
| `Esc` | меню (из игры), закрыть меню |
| `F1` | скриншот в `Screenshots/shotNNNN.bmp` |
| `F2` | сохранить игру |
| `F3` | загрузить игру |
| `F4` | громкость |
| `F5` | яркость |
| `F10` | выход с подтверждением |

## В меню

| Клавиша | Что |
|---|---|
| `↑` `↓` (или `Num 8` / `Num 5`) | выбор пункта |
| `←` `→` (или `Num 4` / `Num 6`) | изменить значение (громкость, яркость, цвет) |
| `Enter` / `Space` | подтвердить |
| `Y` / `N` | ответ на вопрос «вы уверены» |

## Читы

Вводятся прямо в игре, регистр не важен. Работают в одиночной игре и в коопе;
в deathmatch по умолчанию выключены (`-cheat` включает).

| Код | Что делает |
|---|---|
| `IDDQD` | снять 400 единиц урона — «бог» на один раз |
| `UJHTW` | переключить бессмертие |
| `TANK` | 200 жизней и 200 брони |
| `RAMBO` | всё оружие, все ключи, 30000 патронов |
| `BULLFROG` | прыжок ×2 |
| `FORMULA1` | скорость ×3 |
| `,TKSQJHTK` | полёт |
| `CBVCBV` | открыть все двери на уровне |
| `GOODBYE` | выйти с уровня |
| `GJITKYF` + две цифры | прыгнуть на уровень (`GJITKYF05`) |

Коды — это оригинальные последовательности с русской раскладки:
`,TKSQJHTK` набирается как «летающий», `GJITKYF` — «прыгни».

## Аргументы командной строки

Помимо режимов проверки (см. `docs/BUILDING.md`), игра принимает флаги
оригинала:

```
-file <file.wad>   подключить дополнительный WAD или LMP
-config <file>     свой конфиг вместо default.cfg
-warp <N>          начать с уровня N
-width <N>         ширина окна
-height <N>        высота окна
-fullscr           полный экран
-window            оконный режим
-gamma <0..4>      яркость
-sndvol <0..128>   громкость звука
-musvol <0..128>   громкость музыки
-cheat             разрешить читы в deathmatch
```

Часть из них ещё не подключена к конфигу — см. `docs/ROADMAP.md`.
