# Модкит

## Что такое мод Doom2D

Мод — это файл **PK3**, то есть обычный ZIP. Внутри:

| Что | Как попадает в игру |
|---|---|
| `*.wad` | подключается как WAD, по порядку; поздние перекрывают ранние |
| `*.lmp` | заменяет ресурс с тем же именем |
| `*.vgaimg` | заменяет картинку |
| `*.dmi` | заменяет звук |
| `*.dmm` | заменяет песню |

Больше ничего не читается: PNG, звуки в WAV, скрипты и карты Doom/Doom II —
иностранные форматы, у Doom2D своя модель мира. `--modlist` честно показывает,
что загрузится, а что будет проигнорировано.

Мод **перекрывает** встроенное: его трек играет вместо файла из `Data/Music`, его
лампа — вместо лампы базового набора. Это правило важно именно для музыки, потому
что там два источника (XM-файлы и DMM в WAD), и раньше встроенный XM выигрывал
всегда — мод мог положить трек и не услышать его.

### Музыка в моде: два файла, а не один

Трек ссылается на сэмплы **по имени**, а не по номеру. Если положить в мод только
`INTERMUS.dmm`, он загрузится и будет молчать: ноты есть, играть их нечем.
Рядом нужны те `.dmi`, которые трек просит. Посмотреть список:

```powershell
dptdoom2d.exe --modlist mymod.pk3
```

`build.ps1` проверяет это круговым путём: собирает PK3 с треком и сэмплом,
загружает и убеждается, что играет именно он.

## Куда класть

`Data/Mods` — папка установки. Файл, положенный туда, появляется в лаунчере в
разделе «Моды»; включённые галочкой передаются игре как `-file` в том порядке,
в котором отмечены.

## Инструменты

Три команды, встроенные в саму игру — отдельного exe нет:

```powershell
# собрать PK3 из папки (обходит рекурсивно)
dptdoom2d.exe --modbuild mymod.pk3 modsrc\

# что внутри и что из этого загрузится
dptdoom2d.exe --modlist mymod.pk3

# распаковать обратно
dptdoom2d.exe --modunpack mymod.pk3 modsrc\
```

`--modbuild` пишет записи **без сжатия**. Мод Doom2D — это карта на несколько
килобайт и текстуры по несколько сотен байт, так что экономить нечего, зато
архив читается любым инструментом, включая проводник Windows XP, и в нём нет
Deflate, который можно сделать неправильно.

## Структура мода

```
mymod/
├─ maps/
│  └─ mylevel.wad        карта в формате Doom2D
├─ actors.txt            монстры: свойства, спрайты, звуки (см. ACTORS.md)
├─ gfx/
│  ├─ WALL22_1.vgaimg    своя текстура вместо стандартной
│  └─ PLAYA0.lmp         свой спрайт игрока
└─ sound/
   └─ DSPISTOL.dmi       свой звук выстрела
```

Пути внутри архива не важны: имя ресурса берётся из имени файла. Папки нужны
только автору, чтобы не путаться.

## Пример: мод с одной картой

```powershell
mkdir modsrc\maps
copy mylevel.wad modsrc\maps\

dptdoom2d.exe --modbuild mymod.pk3 modsrc\
copy mymod.pk3 Data\Mods\

dptdoom2d.exe -file Data\Mods\mymod.pk3 -warp 1
```

В лаунчере то же самое: положить в `Data/Mods`, отметить галочкой, «Запустить».

## Формат карты

Только родной Doom2D: `"Doom2D"`, `0x1A`, версия 2, дальше блоки. Подробности —
в [MAPS.md](MAPS.md) и [FORMATS.md](FORMATS.md).

Карты Doom/Doom II (`THINGS`, `LINEDEFS`, `SECTORS`, BSP) не поддерживаются и не
будут: это другая игра.

## Что не сделано

Редактор карт и визуальная сборка мода — в [ROADMAP.md](ROADMAP.md). Сейчас
мод собирается командой из готовых файлов; сам контент (карта, текстура, звук)
делается существующими инструментами.

`actors.txt` уже работает: мод может переопределить любого из двадцати
встроенных монстров — свойства, спрайт, звуки, кадры. Новых типов и действий
пока нет; что именно поддерживается — в [ACTORS.md](ACTORS.md).
