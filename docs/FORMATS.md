# Форматы данных

Всё читается байт-в-байт как в оригинале: карты и сохранения Doom2D должны
открываться без конвертации. Числа — little-endian, структуры — `#pragma pack(1)`
(в C# те же поля читаются по одному через `BinReader`, чтобы не тащить `unsafe`).

## WAD

```
offset 0   char id[4]      "IWAD" или "PWAD"
offset 4   int32 count     число элементов
offset 8   int32 dirOfs    смещение каталога
```

Каталог — `count` записей по 16 байт:

```
int32 ofs     смещение данных
int32 len     длина
char  name[8] имя, дополнено NUL
```

Имена сравниваются без учёта регистра и без выхода за 8 символов
(`strncasecmp`). Несколько WAD'ов объединяются: поздние перекрывают ранние.
Файл `.lmp` — сырой ресурс, заменяет одноимённый.

Служебные маркеры в `doom2d.wad`:

| Маркер | Что внутри |
|---|---|
| `S_START` … `S_END` | спрайты |
| `D_START` … `D_END` | звуки |
| `M_START` … `M_END` | музыка (в WAD только имена, сами треки — файлы) |
| `W_START` … `W_END` | стены |

## Изображение (`vgaimg`)

```
uint16 w, h      размер
int16  sx, sy    «горячая точка» (центр спрайта)
byte   pixels[w*h]   индексы палитры, 0 = прозрачный
```

Итого `8 + w*h` байт — ровно столько же, сколько занимает ресурс
(`TITLEPIC` = 8 + 320×200 = 64008).

Спрайты именуются 8 символами: `ИМЯ` (4) + кадр (`A`..`Z`) + поворот (`0`..`9`).
`F_getsprid` ищет по имени и кадру, а бит `0x8000` в результате означает
«зеркальный» спрайт.

## Палитра

| Ресурс | Размер | Что это |
|---|---|---|
| `PLAYPAL` | 768 | 256 цветов × RGB, значения 0..63 (6 бит) |
| `COLORMAP` | 3072 | 12 карт по 256 — затенение |
| `MIXMAP` | 65536 | 256×256 — смешение для дыма |

6-битные значения умножаются на 4 при выводе — так делал SDL.

## Звук (DMI)

```
uint32 len      длина сэмплов
uint32 rate     частота
uint32 lstart   начало цикла
uint32 llen     длина цикла
byte   data[len]   знаковые 8-битные сэмплы
```

`Sound.cs` разворачивает это в 16-битный моно PCM и отдаёт в `SoundEffect`.
Имя ресурса — `DS` + 6 символов, например `DSPISTOL`.

## Карта

```
char  id[8]    "Doom2D\x1A"
int16 ver      версия (2)
```

Дальше — блоки до `MB_END`:

```
int16 t     тип блока
int16 st    подтип (обычно 0)
int32 sz    размер данных
byte  data[sz]
```

| `t` | Блок | Данные |
|---|---|---|
| -1 | комментарий | пропускается |
| 0 | конец | — |
| 1 | имена стен | 256 × (`char name[8]`, `char type`) |
| 2 | задний слой | 100×100 байт, `st=1` — RLE |
| 3 | типы клеток | 100×100 байт, `st=1` — RLE |
| 4 | передний слой | 100×100 байт, `st=1` — RLE |
| 5 | предметы и точки старта | по 8 байт: `int16 x, y, type; uint16 flags` |
| 7 | музыка | имя трека, 8 байт |
| 8 | небо | `int16` тип (1 обычное, 2 гроза, 3 ад) |
| 9 | триггеры | по 9 байт (см. ниже) |

RLE: байт `0xFF`, затем `uint16 count`, затем байт-значение.

Триггер (`switch2_t`):

```
byte x, y     клетка, где висит переключатель
byte t        тип: 1 выход, 3 дверь, 9 телепорт, 10 секрет, …
byte tm       таймер (в файле 0)
byte a, b     целевая клетка
byte c        параметр (для телепорта — не используется)
byte f        флаги: кто и чем нажимает, 0x80 «ещё не нажат»
```

Типы клеток (`fld`):

| Значение | Что | Проходимо |
|---|---|---|
| 0 | пусто | да |
| 1, 2 | стена (2 — открытая дверь) | нет |
| 3 | вода | да |
| 4 | поверхность воды | да (на неё можно встать) |
| 5, 6, 7 | кислота/лава (урон) | да |
| 8 | ловушка-дверь | нет |
| 9, 10 | лифт вверх/вниз | да |
| 255 | закрытая ловушка | нет |

## Сохранение

```
char  name[24]   имя слота (cp1251)
int16 ver        3
```

Затем подряд, без заголовков блоков:

1. `game.c` — флаги, карта, время, точки deathmatch, музыка
2. `view.c` — тип неба, 255 имён стен, флаги, три слоя карты
3. `dots.c`, `smoke.c`, `fx.c` — счётчик + живые записи
4. `items.c` — счётчик + записи + `itm_rtime`
5. `monster.c` — счётчик + записи + `mnum`, `gsndt`
6. `player.c` — игрок 1, (игрок 2), `PL_JUMP`, `PL_RUN`, `p_immortal`
7. `switch.c` — счётчик + записи + `sw_secrets`
8. `weapons.c` — счётчик + записи

Живые записи пишутся только для ненулевых элементов (счётчик), а координаты —
обычные `int32`, поэтому формат не зависит от выравнивания.

## Музыка

Треки — **FastTracker 2 (XM)**: заголовок `Extended Module:`, паттерны,
инструменты с сэмплами. Оригинал отдавал их SDL_mixer'у. Плеер пока не
портирован (см. `docs/ROADMAP.md`).
