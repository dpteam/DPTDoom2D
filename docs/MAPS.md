# Кастомные карты

## Что поддерживается

Только **родной формат Doom2D**. Карты Doom/Doom II (`THINGS`, `LINEDEFS`,
`SECTORS`, BSP) не поддерживаются и не будут: это другая игра с другой моделью
мира. Формат Doom2D — свой, блочный, с тремя слоями клеток 100×100.

Заголовок карты в WAD:

```
0   char  id[6]     "Doom2D"
6   byte  0x1A
7   byte  0
8   int16 ver       1, 2 или 3
```

Дальше идут блоки `{ int16 type; int16 subtype; int32 size; body }` до блока
`End`. Блоки: музыка, небо, палитра стен, предметы/старты, три слоя клеток,
двери/ловушки, комментарий, конец. Подробности — в [FORMATS.md](FORMATS.md).

## Библиотека паков

`Data/Maps` — это **библиотека**, а не список загрузки: 166 WAD'ов эпохи
Doom2D Deluxe (deathmatch-арены, кооп-карты, эксперименты сообщества).

```powershell
dptdoom2d.exe --maps                        # что есть
dptdoom2d.exe -map-pack kozak__arena.wad    # играть этот пак
```

Имя пака — это имя файла; регистр и `.wad` можно опускать. `-warp N` выбирает
уровень внутри пака.

Загружать все сразу нельзя: каждый пак определяет свои `MAP01..MAP19`, и
побеждал бы прочитанный последним. Поэтому — один пак на запуск. В лаунчере это
выпадающий список **Map pack**.

Пак перекрывает встроенные уровни, а не дополняет их: если в паке есть `MAP01`,
играется он.

## Почему карты сообщества «ломались»

Две вещи, на которых оригинальный движок падал, а порт — нет:

**1. Чужие текстуры.** Пак строился под другой набор стен, поэтому просит
`WALL63_1`, `WS19_1`, имена в CP1251 и т.п. Раньше это был `Fatal` на первой же
незнакомой текстуре. Теперь:

```
WARN  map texture not found: 'WALL63_1' (using a stand-in)
```

Стена рисуется запасной текстурой (`WALL22_1`), уровень играется. Полный список
недостающих имён — в логе, так что пак можно починить.

**2. Нет одиночного старта.** Большинство DM-паков содержит только DM-старты.
Раньше — `Fatal: Предмет игрок_1 не найден`. Теперь режим следует за картой:

```
WARN  map has no single-player start, switching to deathmatch
```

Если стартов нет вообще, игрок появляется в центре карты. Кооп на карте с одним
стартом сажает обоих на одну точку (как делал оригинал для второго игрока).

**3. Больше предметов, чем в таблице.** Таблица — 300 записей. Лишние
отбрасываются с предупреждением, вместо выхода за границы массива.

## Редактор карт

Исходники редактора лежат в `refs/D2D_Also/DOOM/Doom2D/DELUXE/LEVELS`
(`EDIT.CPP`, `THING.C`, `EDITOR.CFG`) — это DOS-редактор с собственным VGA-UI.
Его перенос — отдельная работа (см. [ROADMAP.md](ROADMAP.md)); пока карты
делаются существующим редактором, а порт их просто читает.

## Как добавить свою карту

1. Сделать WAD в формате Doom2D (редактор Deluxe или совместимый).
2. Положить его в `Data/Maps`.
3. Запустить `-map-pack <имя файла>`.

Ничего пересобирать не нужно: папка читается при старте.
