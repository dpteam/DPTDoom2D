# Прототипы

## Что это

В `refs/D2D_Also` лежит рабочий архив Prikol Software: кроме исходников самого
Doom2D там собраны программы, из которых игра выросла — дым, генераторы мира,
платформер, лабиринт, сборщик WAD. Часть из них — на C и ассемблере под DOS, часть
на Turbo Pascal.

Здесь они переписаны на C# и запускаются из лаунчера (**Прототипы**) или с
командной строки:

```powershell
dptdoom2d.exe --proto-list      # что есть
dptdoom2d.exe --proto truba     # запустить в отдельном окне
```

Данные игры для них **не нужны**: каждый прототип приносит своё artwork, а оно
вкомпилировано в exe.

## Что перенесено

| id | Программа | Исходники | Что делает |
|---|---|---|---|
| `truba` | TRUBA | `oldprog/watcom/PROG/TRUBA` | Дым в туннеле, 2000 частиц. Отсюда `smoke.c` |
| `planet` | PLANET | `oldprog/watcom/PROG/PLANET` | Генератор планеты: континенты, климат, ветер, осадки |
| `landgen` | LANDGEN | `oldprog/watcom/PROG/TEST` | Фрактальный ландшафт из value-шума |
| `escapade` | ESCAPADE | `oldprog/TC/PROGS/ESCAPADE` | Платформер: поле 64x64, герой, анимации |
| `vgamaze` | VGA MAZE | `oldprog/TC/PROGS/VGAMAZE` | Лабиринт из тайлов со скроллом |
| `doomwad` | DOOM WAD MAKER | `oldprog/TC/PROGS/DOOMWAD` | Сборщик WAD из списка файлов |

## Запуск и управление

| Прототип | Клавиши |
|---|---|
| TRUBA | `Esc` — выход |
| PLANET | стрелки — скролл, `Space` — карта осадков, `Esc` — выход |
| LANDGEN | `R` — новый мир, `Esc` — выход |
| ESCAPADE | стрелки — идти, `Up` — прыжок, `Space` — огонь, `Esc` — выход |
| VGA MAZE | стрелки — идти, `Space` — новый лабиринт, `Esc` — выход |

`F11` в любом прототипе переключает полный экран — как в игре. Режим растяжения
(`pixel` / `nearest` / `smooth`) берётся из тех же настроек, с которыми запущена
игра, а не задаётся жёстко: `PixelPerfect` — правильный режим по умолчанию для
320×200, но не единственный. Подсказку `ESC EXIT  F11 FULLSCREEN` рисует сам хост
первые три секунды, чтобы способ выйти из окна без заголовка не приходилось
угадывать.

## Как это устроено

Каждый прототип — три метода:

```csharp
public override void Init();              // один раз, после установки палитры
public override void Frame(int frame);    // один кадр
```

`ProtoHost` даёт окно, цикл, масштабирование, ввод и маленький шрифт 3×5 для
подсказок. Окно своё, а не игровое: недоделанная демка не может испортить
состояние игры, а закрытие окна — это и есть выход.

Исходники DOS-версий рисовали в VGA напрямую и работали с палитрой через порты.
Здесь то же самое делает `Vga`/`Palette` из порта, поэтому код прототипа
выглядит почти как оригинал: те же формулы, те же константы, те же спрайты.

## Артворк

Пять контейнеров `.VGA` (формат `VGAED`/`VGAED2`: палитра + каталог картинок)
вкомпилированы в `Prototypes/ProtoAssets.cs` как base64 — по одному блобу на
файл. Так прототип запускается сразу после сборки, без копирования данных, и
бинарников в репозитории нет.

Пересобрать после замены арта:

```powershell
./DPTDOOM2D/tools/make-proto-assets.ps1
```

## Что осталось в архиве

Не перенесено и, скорее всего, не будет: `D2D_Avlibs4g` (свои VGA/SVGA/SOUND
библиотеки — у порта своя платформа), `watcom/PROG/MAKE`, `LINK`, `LIBS`
(инструменты сборки DOS), архивы Turbo C (`TCPROGS.ARJ`, `TCMISC.ARJ`) — это
чужой тулчейн.

Кандидаты на перенос позже:

| Что | Зачем |
|---|---|
| `d2d_texconv` (BMP ↔ WAD-текстуры) | нужен вместе с редактором карт |
| `oldprog/watcom/PROG/FILM` | формат `.FLM`, проигрыватель видео |
| `oldprog/watcom/PROG/PH2D` | 3D-меш с текстурами, предок `a8.c` |
| `oldprog/watcom/PROG/VGA3D` | текстурированный рельеф с высот, предок неба |
| обратный конвертер XM → DMM | чтобы свои треки класть прямо в WAD |

См. [ROADMAP.md](ROADMAP.md).
