# Doom 2D — XNA/FNA port

**Doom 2D** (Prikol Software, 1996) rewritten on XNA/FNA. Same gameplay, modern
engine.

- **[README.md](../README.md)** — overview, screenshots, quick start (Russian)
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — layers, the software renderer, module map
- **[FORMATS.md](FORMATS.md)** — WAD, sprites, maps, saves, DMI
- **[BUILDING.md](BUILDING.md)** — build, packaging, CI, headless checks
- **[CONTROLS.md](CONTROLS.md)** — keys and cheats
- **[ROADMAP.md](ROADMAP.md)** — what is left (the XM music replayer)
- **[PORTING.md](PORTING.md)** — port log: decisions and pitfalls

Everything except the README is in Russian; the code and its comments are in
English, so a developer who does not read Russian can still work on it.
