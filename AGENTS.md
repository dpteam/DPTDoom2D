# Общие правила для агентов и контрибьюторов

## Что это за проект

Порт Doom2D (1996, Prikol Software) на C#/XNA/FNA. Геймплей переносится
**один-в-один**; менять поведение игры — только если это баг порта, а не
«улучшение».

## Железные правила

1. **Геймплей не переписывать «как красивее».** Порядок вызовов в тике, формулы
   урона, скорости, тайминги (`DELAY 50`, 20 тиков в секунду) — это поведение
   игры. Сомневаешься — сверься с `refs/doom2d-rembo/src/*.c`.
2. **Рендер остаётся программным.** `Vga.Buffer` — 8-битные индексы палитры.
   Не переводи спрайты на `Texture2D`, не «оптимизируй» `clrmap`/`mixmap`:
   на этом держится совпадение картинки с оригиналом.
3. **Форматы не менять.** WAD, карты, сохранения (`ver=3`) читаются как есть.
   Если нужен новый формат — это новая версия, а не правка старого.
4. **`external/fna` не редактировать.** Это вендорная копия FNA (Ms-PL).
   Нужен шим — делай его в `Doom2D/Fna/` (пример: `TerrariaLogShim.cs`).
5. **Никаких новых зависимостей без нужды.** Проект собирается из .NET SDK и
   того, что лежит в репозитории.

## Куда что класть

| Что | Куда |
|---|---|
| платформенный код (файлы, ввод, звук, палитра) | `Doom2D/Engine/` |
| игровая логика (мир, игрок, монстры, меню) | `Doom2D/Game/` |
| проверки без окна, отладочные режимы | `Doom2D/Headless.cs` |
| скрипты сборки/упаковки | `Doom2D/tools/` |
| документация | `docs/` |

Один модуль — один файл, соответствующий C-файлу оригинала; имя файла C#
совпадает с C-шным (`monster.c` → `Monsters.cs`).

## Стиль кода

- C# в стиле остального проекта: `static`-классы, поля с заглавной буквы,
  комментарии по-английски, документация по-русски.
- Комментарий объясняет **почему**, а не «что»: `// как в monster.c: атм
  сбрасывается только при удачном выстреле`.
- Ссылка на оригинал в комментарии — норма: `// Z_moveobj`, `// switch.c`.

## Перед коммитом

```powershell
./Doom2D/tools/build.ps1 -Test
```

Это прогон настоящего игрового цикла без окна: 19 карт, сохранения, фронтенд.
Он должен проходить целиком. Если менял рендер — посмотри кадр:

```powershell
Doom2D.exe --simulate 300 out.bmp 1 "5:right,40:fire"
```

## Документация

Меняешь поведение или добавляешь модуль — обнови `docs/`. Скриншоты в `docs/images`
генерируются из игры (`tools/make-docs-images.ps1`), вручную их не правят.
